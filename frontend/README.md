# Ledgerly Frontend

**Status:** Phase 0 — Scaffolded Placeholder

The frontend application for Ledgerly will be initialized in Sprint Phase 4 using **Vite + React + TypeScript + TailwindCSS / Accessible UI Component foundation**, matching the architecture specified in `docs/03_Architecture.md` §4.3.

## Planned Technology Stack:
- **Build tool:** Vite
- **Framework:** React 18+ with TypeScript
- **State Management / Data Fetching:** TanStack React Query (server-state caching)
- **Styling:** Tailwind CSS / Vanilla CSS with design token variables
- **Form Validation:** React Hook Form + Zod

## Planned Core Screens for 14-Day Demo:
1. Multi-tenant Registration & Login
2. Organization Switcher
3. Customer & Catalog Management
4. Invoice Creation & Preview (Dynamic line-item recalculation)
5. Invoice Issuance & Detail View (Legal Snapshot display)
6. Customer Payment & Allocation Modal
7. Real-Time Trial Balance & General Ledger Cards
